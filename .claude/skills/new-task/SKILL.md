# /new-task — 開任務單

輸入：`$ARGUMENTS`（標題，選填目標版本；沒給版本就用 pyproject 目前 version 的下一個 patch）。

## 步驟

1. **檢查唯一活檔規則**：`docs/tasks/` 內若已有 `Status: active` 的任務單，先問使用者要結案它、改 draft、還是併進去。不要直接開第二份 active。
2. **開工前查證（Pre-flight）**：把這次任務會依賴的事實列出來，逐條用 grep／read／執行查證，結果填進表格。若任務承接 `docs/limits.md` 或上一份任務單留下的條目，**先查證它還成立**再帶入；不成立的在原處標「作廢」並寫證據。
3. **複製模板**：`docs/_templates/TASK.md` → `docs/tasks/<今天 YYYY-MM-DD>-v<版本>-<英文短標題>.md`。刪首行 HTML 註解。`##` 標題不可改。
4. **填內容**：
   - 目標：一句話 + 遠因與近因
   - 裁定紀錄：使用者到目前為止說過的原話，逐字；需要裁定但還沒裁的寫 ⬜ Pending
   - 範圍／明確不做／要改的檔案（含**不需修改的部分**）／驗收條件（每條附驗證指令）／進度
5. **Status**：有 ⬜ Pending 就留 `draft` 並停下等裁定；沒有就改 `active`，Expiry `[until: v<版本>]`。
6. **STATUS.md**：「目前在做」寫上這份任務單的連結，Updated 改今天。
7. 回報檔案路徑、Pending 項目、下一步。

## 不做
- 不在任務單裡寫「大概」「應該」的事實；查不到就標 ⚠ 未證實。
- 不自行裁定設計偏好。
